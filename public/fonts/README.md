# Fonts

The app self-hosts Archivo and JetBrains Mono so the TV renders without a font CDN. Latin and Latin Extended subsets cover Polish and international names without fallback layout shifts.

Both families are bundled unmodified under the SIL Open Font License 1.1:

- [Archivo](https://github.com/Omnibus-Type/Archivo) — Omnibus-Type;
- [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) — JetBrains.

The linked repositories contain the full licence texts.
